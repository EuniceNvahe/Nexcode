# Nexcode
Este é um repositório que contém o codigo de criação da página do nexcode

NEXCODE - WEBSITE

Ficheiros:
- index.html: página inicial
- portfolio.html: página com todos os projectos
- style.css: estilos do website
- script.js: menu, ano automático e formulário
- imagens/logo-nexcode.png: logótipo


IMPORTANTE:
Os cartões do portfólio são modelos de preenchimento, não projectos reais confirmados.
Substitua nomes, categorias, descrições, imagens e links pelos trabalhos efectivamente
realizados e publicados pela NEXCODE. No portfolio.html, procure por "Nome do projecto".

O formulário utiliza mailto: abre o programa de e-mail do visitante. Para receber
mensagens directamente no website será necessário ligar um serviço de formulários
ou desenvolver uma parte de servidor
